A one-line pickup line aimed at an AI, written in TypeScript for the make.fun "Robot Romance" competition.

## Run it

```bash
node main.ts
```

Outputs a single joke pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt`).
